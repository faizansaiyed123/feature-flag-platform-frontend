# Feature Flag Platform — Frontend

Next.js App Router frontend for the Feature Flag Platform.

## Current phase

Foundation only. The app shell is intentionally small until the backend contracts and domain model are implemented.

## Stack

- Next.js 16.3
- React 19.3
- TypeScript
- App Router

## Local development

Requirements:

- Node.js 22+
- npm 10+

```bash
npm install
npm run dev
```

The application will run at `http://localhost:3000`.
